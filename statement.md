PROBLEM STATEMENT :-
    to perform the calculation, user requires to re-enter the number and operator to get the desired result.
    contains the chained arithmetic calculations for the continous calculation.
    simple calculator to track every input the operator to display the result.

SCOPE OF THE PROJECT :-
    It allows the user to input the arithmetic operators like +, -, *, /
    it uses the heigher mathematics for example trigo and log and expoentiation.
    can handle the decimal point numbers as float.
    have the CLEAR button to clear the screen and EXIT button to close the calculator.
    Can run locally on any system.

Target Users :-
    Students for the fast calculations.
    first sem student to build  their first project.

High Level features :-
    contains the continous operations until the user input the EXIT or CLEAR command.
    Contains the guidelines for division with zero.
    have the result resetting.
