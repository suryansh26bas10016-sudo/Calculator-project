Project Title :-
    MY CALCULATOR      

Overview :-
    Performs the basic arithmetic calculations of +,-,*,/
    also have two special buttons CLEAR and EXIT

Features :-
    arithmetic operators i.e. +, -, *, /
    CLEAR to clear the results and EXIT to close the calculator
    it uses the gui mode in which the layout of the calculator will be displayed on the screen
    There is the use of higher mathematics for example trigonometry functions and logarithmic and exponentiation function is used.

Technology use :-   Python 3.14.7


HOW TO OPEN THE PROJECT
Download all the files to the system then use the following commands.
1.  locate the code<> button on top right side of the github interface
2.  download the files as zip folder
3.  extract the folder
4.  open the main.py in vs-code
5.  run the command
6.  the calculator interface will pop-up.


Instructions for testing :-
    1. run the program 
    2. the calculator layout will be displayed
    3. with you cursor locate the buttons and then get your desired answers by clicking on the equal marks.

STEPS TO BE FOLLOWED:-
first enter any number
enter the operator or the functions
enter the second number
hit equal to get the desired result


NOTE :-
    CLEAR and EXIT both are case sensitive and should be typed in capital ONLY
